# Mathushan & Nicoline's Wedding Invitation

This is a static wedding invitation site built with HTML, CSS, and JavaScript. It has no build step or package dependencies. Keep the HTML, CSS, JavaScript, and media files together in the same directory.

## Run locally

From the repository directory, start a local web server:

```sh
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in a browser, then select **Tap to open invitation**. A local server is recommended so the browser can load the video, audio, and photo assets correctly.

The RSVP form opens a prefilled WhatsApp message for sending; it does not submit to a server or store responses on this site.
